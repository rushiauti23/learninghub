Follow one web request down the TCP/IP stack and back up

Your computer sends a single HTTP request. Each layer wraps it in its own header, a router rewrites part of it, and the receiver unwraps it layer by layer. Every byte, checksum and address on this page is computed in your browser.

Damage in transit

Your computer is 192.168.1.20 on 192.168.1.0/24, with a gateway at 192.168.1.1.

How this maps to other models. The TCP/IP model has four layers. In the seven-layer OSI model, Application covers layers 5 to 7, Transport is layer 4, Internet is Network (layer 3), and Link covers Data link (layer 2) and Physical (layer 1). The wire step is drawn separately here because it is easy to overlook.

What is simplified. One router sits between you and the server. There is no TLS or NAT, the link is wired Ethernet rather than Wi-Fi, and the TCP handshake is shown as a diagram rather than as bytes. The addresses 203.0.113.0/24 are reserved for documentation, so no real server answers there.
